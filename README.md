# ☕ Cafeteria Quarteto — Projeto Final

> Projeto de website responsivo desenvolvido para a disciplina de **Gerência de Configuração e Mudanças**.

---

## 📌 Sobre o Projeto

A **Cafeteria Quarteto** é um site institucional e interativo criado para apresentar uma cafeteria moderna e acolhedora. O projeto conta com navegação entre páginas, apresentação do cardápio de cafés e acompanhamentos, informações da empresa e formulário de contato.

## 📂 Estrutura do Repositório

```text
projeto-final-quarteto-fantastico/
├── index.html           # Página inicial (Home)
├── cardapio.html        # Página do Cardápio / Produtos
├── sobre.html           # Página Sobre a Cafeteria
├── contato.html         # Página de Contato e Localização
├── css/
│   ├── style.css        # Estilos globais e compartilhados
│   ├── HomeStyle.css    # Estilos específicos da Home
│   ├── CardapioStyle.css# Estilos específicos do Cardápio
│   └── SobreStyle.css   # Estilos específicos da página Sobre
└── img/                 # Imagens do projeto (fundo, produtos, etc.)

```

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todas as páginas.
* **CSS3:** Estilização modularizada, layout responsivo e design visual.
* **Git & GitHub:** Controle de versão, gerenciamento de branches e histórico de alterações.
* **GitHub Pages:** Hospedagem e publicação do site.

## 🚀 Como Executar o Projeto Localmente

1. **Clonar o repositório:**
```bash
git clone https://github.com/Gerencia-de-configuracao-e-mudancas/projeto-final-quarteto-fantastico.git

```


2. **Acessar a pasta do projeto:**
```bash
cd projeto-final-quarteto-fantastico

```


3. **Abrir no navegador:**
Basta dar um duplo clique no arquivo `index.html` ou abri-lo diretamente com qualquer navegador web de sua preferência.
